# Story Studio

Story Studio is an AI-powered storytelling web application built using Python, Gradio, and Google's Gemini API. It generates immersive, customizable stories based on user inputs such as genre, tone, target audience, language, and story length.

## Live Demo

https://story-studio-6qn1.onrender.com/

## Features

- AI-powered story generation using Google Gemini
- Multiple genres and storytelling tones
- Audience-specific story generation
- Adjustable story length
- Multi-language support
- Structured narratives with titles, dialogue, scenes, and cliffhanger endings

## Tech Stack

## Installation

Clone the repository:

```bash
git clone https://github.com/pritichha15/story-studio.git
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Create a `.env` file and add your Gemini API key:

```text
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application:

```bash
python app.py
```
